# UI/UX 设计规范

## 1. 颜色主题

| 用途 | 色值 | 说明 |
|------|------|------|
| 窗口背景 | `#FFF0F0` | 极淡粉色，整体基调 |
| 卡片背景 | `#FFFFFF` | 白色，干净清晰 |
| 主色调 | `#FFB6C1` | 淡粉，按钮/选中态 |
| 主色调深 | `#FF9CB5` | 稍深粉，hover态 |
| 标题文字 | `#333333` | 深灰，高可读性 |
| 内容文字 | `#666666` | 灰色，正文 |
| 辅助文字 | `#999999` | 浅灰，时间戳等 |
| 卡片阴影 | `rgba(0,0,0,0.08)` | 轻微阴影，层次感 |
| 置顶标记 | `#FFE4B5` | 淡橙色，区分置顶 |
| 边框 | `#F0E0E0` | 极淡粉灰，分割线 |

## 2. 窗口规格

- **默认尺寸**: 280 × 200px
- **最小尺寸**: 160 × 140px
- **圆角**: 整体窗口圆角 8px，卡片圆角 6px
- **内边距**: 窗口 padding 16px，卡片 padding 12px

## 4. 组件规范

### 标题栏 (TitleBar)
- 高度: 28px
- 左侧: 软件名称 "历史粘贴板"，字体 11px 加粗
- 右侧: 设置按钮 + 最小化按钮 + 关闭按钮（悬停变色）
- 支持拖拽移动窗口

### 工具栏 (ToolBar)
- 高度: 32px
- 搜索框: 左侧，icon + input，自适应宽度
- 类型筛选: 右侧，下拉选择器，三个选项

### 卡片列表 (CardList)
- 虚拟滚动: 只渲染可视区域内的卡片（千级数据流畅）
- 分区: "已置顶"区域 + "最近记录"区域
- 每个分区之间间距 8px

### 文字卡片 (TextCard)
- 白色背景，圆角 6px，阴影
- 文字区域: 最多显示 2 行（约 100 字符），超出省略号
- 底部栏: 时间戳（左）+ 操作按钮（右）
- 时间戳格式: "2026-05-11 14:30"
- 操作按钮: 复制（主色按钮）、置顶/取消置顶（文字链接）、删除（灰色文字）

### 图片卡片 (ImageCard)
- 与文字卡片相同布局
- 内容区域: 120×80 缩略图，居中
- 点击缩略图触发大图预览

### 图片预览 (ImagePreview)
- 全屏半透明黑色遮罩
- 大图居中显示，最大宽高不超过窗口 90%
- 点击遮罩区域关闭

## 5. 交互细节

| 操作 | 反馈 |
|------|------|
| 按钮 hover | 颜色加深，cursor: pointer |
| 卡片 hover | 轻微上移 2px，阴影加深 |
| 搜索输入 | 300ms 防抖后筛选 |
| 复制成功 | 按钮短暂显示"已复制!" 1.5s 后恢复 |
| 删除 | 卡片淡出动画 200ms 后移除 |
| 置顶切换 | 卡片移动到置顶区/普通区 |
| 窗口贴边 | 距离边缘 < 20px 时吸附到边缘 |
| 关闭窗口 | 隐藏到托盘，不退出程序 |

## 6. 字体

- 使用系统默认字体:
  - `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 字号层级: 标题 14px, 正文 13px, 辅助 12px

# 详细开发执行计划

## 开发原则

1. **增量开发**：每步都是可运行、可验证的小版本
2. **验证驱动**：每完成一步必须验证通过，再进入下一步
3. **日志优先**：每次开发前读日志，开发后写日志
4. **问题记录**：遇到问题记录原因和解决方案

## Step 1: 项目初始化 + Electron 空壳

### 目标
项目能启动，看到空白窗口，系统托盘有图标，全局快捷键能呼出/隐藏窗口。

### 任务
1. 使用 `npm create @electron-vite` 初始化项目（React + TypeScript）
2. 安装必要依赖
3. 创建 `src/main/index.ts` — 主入口，创建 BrowserWindow
4. 配置系统托盘（Tray），右键菜单
5. 注册全局快捷键（Win+V）
6. 窗口关闭行为：点击 × 隐藏到托盘

### 验证
- `npm run dev` 启动后弹出窗口
- 系统托盘出现图标
- 按 Win+V 窗口显示/隐藏
- 点击 × 窗口隐藏，不退出

---

## Step 2: 数据库模块

### 目标
数据能存、能查、能删，过期自动清理。

### 任务
1. 安装 better-sqlite3
2. 创建 `src/main/database.ts`
3. 初始化数据库和表结构
4. 实现: `insertRecord()`, `queryRecords()`, `deleteRecord()`, `togglePin()`, `searchRecords()`, `filterByType()`
5. 实现: `cleanExpired()` — 删除超过7天的记录（置顶除外）
6. 应用启动时调用 cleanExpired()，同时每1小时检查一次

### 验证
- 插入数据后查询返回正确结果
- 搜索功能匹配内容
- 删除操作后数据消失
- 置顶切换后字段更新

---

## Step 3: 剪贴板监听

### 目标
用户复制内容后，自动记录到数据库。

### 任务
1. 创建 `src/main/clipboard.ts`
2. 每 500ms 读取系统剪贴板
3. 检测内容变化（文字去重）
4. 图片剪贴板检测，保存到 images/ 文件夹
5. 调用 database.ts 插入记录

### 验证
- 复制文字 → 数据库增加记录
- 复制图片 → images/ 有文件 + 数据库有记录
- 复制相同内容不重复记录

---

## Step 4: IPC 通信

### 目标
UI 能调用主进程数据库功能。

### 任务
1. 创建 `src/main/ipc.ts`
2. 注册 IPC handlers: `clipboard:query`, `clipboard:search`, `clipboard:delete`, `clipboard:pin`, `clipboard:copy`
3. 在 preload script 中暴露 API
4. 渲染进程通过 `window.electronAPI` 调用

### 验证
- 渲染进程能查询数据库
- 渲染进程能删除记录
- 渲染进程能触发置顶切换
- 渲染进程能复制内容到剪贴板

---

## Step 5: 主窗口 UI

### 目标
完整的卡片列表界面，可搜索、可筛选。

### 任务
1. 实现淡粉色主题 CSS
2. 实现自定义标题栏
3. 实现搜索栏（300ms 防抖）
4. 实现类型筛选下拉
5. 实现卡片列表（时间降序，置顶优先）
6. 实现文字卡片（预览2行）
7. 实现图片卡片（缩略图）
8. 实现图片预览弹窗
9. 实现复制、置顶、删除按钮

### 验证
- 卡片按时间倒序排列
- 置顶卡片在顶部
- 搜索实时筛选
- 类型切换正确过滤
- 图片点击弹出大图

---

## Step 6: 高级功能

### 目标
完整用户体验。

### 任务
1. 屏幕吸附（< 20px 贴边）
2. 自定义背景图（文件选择 + 透明度滑块）
3. 复制后自动隐藏窗口
4. 开机自启（electron 的 app.setLoginItemSettings）

### 验证
- 窗口拖到边缘自动吸附
- 设置背景图后背景更换
- 点击复制后窗口自动隐藏
- 重启电脑后软件自动启动

---

## Step 7: 打包发布

### 目标
生成可安装的 .exe 文件。

### 任务
1. 配置 electron-builder
2. 添加应用图标
3. 配置 nsis 安装程序（中文安装界面）
4. 打包测试

### 验证
- 打包成功生成 .exe
- 安装到另一台 Windows 正常运行
- 开机自启正常
- 所有功能正常

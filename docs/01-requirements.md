# 需求规格说明书

## 1. 项目概述

一个运行在 Windows 上的剪贴板历史记录软件，自动记录用户所有复制的内容（文字和图片），支持搜索、置顶、删除，以淡粉色卡片界面展示。

## 2. 功能需求

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F1 | 开机自启 | 电脑开机后软件自动在后台运行 | P0 |
| F2 | 系统托盘 | 运行后缩放到系统托盘，右键菜单含"打开主面板"和"退出" | P0 |
| F3 | 剪贴板监听 | 实时监听剪贴板变化，自动记录文字和图片 | P0 |
| F4 | 存储期限 | 保留最近7天的记录，7天前的自动清理（置顶内容不受影响） | P0 |
| F5 | 卡片展示 | 主窗口以时间降序排列所有记录卡片 | P0 |
| F6 | 类型筛选 | 支持"全部 / 文字 / 图片"三种视图切换 | P1 |
| F7 | 复制粘贴 | 点击卡片上的"复制"按钮，内容复制到剪贴板 | P0 |
| F8 | 置顶功能 | 重要卡片可以置顶，始终显示在列表最上方 | P1 |
| F9 | 删除功能 | 删除不需要的记录（不弹确认，直接删除） | P1 |
| F10 | 搜索功能 | 搜索框输入文字，实时筛选匹配的文字类记录 | P1 |
| F11 | 全局快捷键 | 按 Win+V 呼出/隐藏主窗口 | P1 |
| F12 | 图片预览 | 图片卡片显示缩略图，点击弹出大图预览 | P1 |
| F13 | 可调窗口 | 窗口可自由拖拽调整大小 | P2 |
| F14 | 屏幕吸附 | 窗口靠近屏幕边缘时自动吸附贴边 | P2 |
| F15 | 自定义背景 | 用户可选择本地图片作为窗口背景，可调透明度 | P2 |
| F16 | 复制后隐藏 | 点击复制后窗口自动隐藏到托盘 | P2 |

## 3. 非功能需求

| 编号 | 需求 | 描述 |
|------|------|------|
| NF1 | 本地存储 | 所有数据存储在本地，不上传云端 |
| NF2 | 隐私安全 | 无网络请求，不收集任何用户数据 |
| NF3 | 性能 | 千级记录下流畅滚动，无明显卡顿 |
| NF4 | 稳定性 | 后台运行 7×24 小时不崩溃、不泄漏内存 |

## 4. 验收标准

1. 软件安装后开机自动启动，系统托盘有图标
2. 复制任意文本 → 打开软件 → 看到对应卡片
3. 截图或复制图片 → 看到缩略图
4. 搜索关键词 → 只显示匹配的记录
5. 切换到"图片" → 只显示图片记录
6. 点击置顶 → 卡片固定到顶部
7. 点击删除 → 卡片消失
8. 点击复制 → 内容复制成功，窗口隐藏
9. 窗口拖到边缘 → 自动吸附
10. 设置背景图 → 背景更换成功
